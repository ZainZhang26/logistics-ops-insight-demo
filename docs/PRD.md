# 物流网点营运监控与智能诊断产品需求文档

## 产品背景

片区运营经理通常需要从多个报表中查找异常，指标口径不统一，异常原因依赖人工经验判断，难以及时形成处置与复盘闭环。本产品用统一指标、异常排序和证据化诊断降低日常巡检成本。

## 目标用户

- 片区运营经理：关注辖区整体时效、质量和产能。
- 网点负责人：关注本网点的异常环节和可执行动作。
- 数据产品或分析人员：维护指标口径、异常规则与效果评估。

## 核心任务

1. 在一分钟内判断片区是否出现明显异常。
2. 定位受影响网点、日期、线路或作业环节。
3. 获得包含证据和置信度的候选原因。
4. 选择运营动作并持续观察相关指标。

## MVP 功能

### 营运总览

展示运单量、时效达成率、破损率、平均时长、产能利用率和积压量；支持日期与片区筛选、趋势查看和网点排名。

### 异常诊断

按照历史基线偏离、破损变化、产能负荷、积压和 P90 时长计算异常分，区分高、中、低等级。对日运单量较少的网点，时效、破损和时长偏离按样本量折减，避免单票波动挤占异常榜首。

### 异常下钻

展示网点当日指标、异常环节分布、诊断摘要、置信度和运营建议。系统只输出候选原因，不把统计相关性表述为确定因果。

### 网点画像

展示单个网点的历史趋势、核心指标、产能与积压以及异常记录。

### Excel 数据导入

提供可下载的标准演示表格。用户上传 `.xlsx` 后，系统校验必需工作表、字段类型、主键唯一性、跨表引用和敏感字段；校验通过的数据写入会话级临时 DuckDB，三个分析页面统一切换数据源，并可一键恢复内置数据。

## 非目标

- 当前版本不连接真实生产系统。
- 当前版本不处理个人信息。
- 当前版本不承诺预测业务收益。
- 大模型不直接执行运营动作，也不作为异常检测的唯一来源。

## 验收标准

- 首次启动能够自动生成数据并进入产品页面。
- 标准演示 Excel 能通过校验并驱动全部分析页面；错误结构必须给出可操作的提示。
- 三个核心页面使用相同指标口径。
- 已注入的场景能够在异常列表或网点画像中被观察到。
- 数据生成使用固定随机种子时结果一致。
- 指标和数据模型具备自动化测试。
